# CaféNotas (BrewTrack) ☕

Aplicación nativa de Android diseñada para registrar y valorar catas de café de especialidad. Este proyecto es una práctica académica enfocada en la correcta gestión de recursos, internacionalización y diseño de interfaces sin código funcional complejo.

## Características Principales
*   **Interfaz escalable:** Diseño mediante ConstraintLayout/LinearLayout adaptable a teléfonos y tablets.
*   **Gestión de recursos estáticos:** Ningún texto, color ni tamaño está *hardcodeado* en el código de la vista. Todo se gestiona desde `/res/values`.
*   **Internacionalización:** Soporte nativo para Español e Inglés (`values-en`).
*   **Estilos y Temas:** Paleta de colores personalizada con temática de café e implementación de estilos reutilizables.
*   **Icono adaptativo:** Iconografía vectorial implementada a través de las carpetas mipmap.

## Requisitos del sistema
*   **API Mínima:** 24 (Android 7.0 Nougat)
*   **Lenguaje:** Java
*   **Entorno:** Android Studio

## Cómo ejecutar el proyecto
1. Clona este repositorio en tu equipo local:
2. Abre Android Studio y selecciona **File > Open**.
3. Navega hasta la carpeta clonada y selecciona el directorio raíz del proyecto.
4. Espera a que Gradle termine de sincronizar las dependencias.
5. Selecciona un dispositivo virtual (AVD) o conecta un dispositivo físico mediante depuración USB.
6. Pulsa el botón **Run 'app'** (Shift + F10) en la barra superior.
